# EOS ≡ P/T nets — Lean 4 formalization

Lean 4 formalization accompanying the paper

> L. H. Costa Neto and E. H. Haeusler, *On the Observational Equivalence of Object
> Petri Nets and Place/Transition Nets*.

It mechanizes the core of the paper's main result: for every Elementary Object
System (EOS) under reference semantics, the labelled transition system of the EOS
and that of the equivalent P/T net built from it are bisimilar, with identical
labels on both sides.

The formalization is built on [CSLib](https://github.com/leanprover/cslib) and
uses its definitions of labelled transition systems (`Cslib.LTS`) and
bisimulation (`Cslib.LTS.IsBisimulation`).

## Main theorem

`Dissertation.eos_bisimulation` in [`EOS/Equivalence.lean`](EOS/Equivalence.lean):

```lean
theorem eos_bisimulation :
    Cslib.LTS.IsBisimulation (eosToLTS E) (PTNet.toLTS (eosEquivNet E)) (eosStateRel E)
```

It rests on two lemmas, in the same file:

- `eosEquivNet_enabled_iff`: an action is enabled in the EOS iff the corresponding
  transition is enabled in the equivalent net;
- `eosEquivNet_fire_eq`: firing commutes with the translation of markings.

The proof contains no `sorry`, and `#print axioms Dissertation.eos_bisimulation`
reports only `propext` and `Quot.sound`.

## Correspondence with the paper

| Paper | Lean |
|---|---|
| P/T net, firing rule | `Cslib.PetriNet.PTNet`, `PTNet.Enabled`, `PTNet.fire` (`PetriNet/Basic.lean`) |
| Transition system generated by a P/T net | `PTNet.toLTS` (`PetriNet/Semantics.lean`) |
| Bisimulation | `Cslib.LTS.IsBisimulation` (CSLib) |
| EOS structure | `EOS` (`EOS/Basic.lean`) |
| EOS marking under reference semantics | `EOSSysMark`, `EOSMarking` |
| Empty transition | `TauOr` |
| Action, enabling and firing | `EOSAction`, `EOSAction.Valid`, `EOSAction.Enabled`, `EOSAction.fire` |
| EOS as transition system | `eosToLTS` |
| Equivalent P/T net | `eosEquivNet` (places `EOSPlaces`) |
| Equivalent marking | `eosToPTMarking` |
| Main theorem (bisimulation) | `eos_bisimulation` (`EOS/Equivalence.lean`) |

Scope and differences with respect to the paper:

- The bisimulation is mechanized. The other two properties stated in the paper's
  theorem (preservation of the total number of tokens and of the partial order
  between markings) follow from the translation of markings and are not
  formalized here; injectivity of the translation is proved
  (`eosToPTMarking_injective`).
- Places and transitions may be arbitrary types, not necessarily finite, so the
  result is slightly more general than in the paper.
- The place sets of the system net and of the object nets are disjoint by
  construction (sum and sigma types), which the paper states as an assumption.

`PetriNet/` and `PetriNetTests/` contain the general P/T net development
(reachability, its agreement with `LTS.CanReach`, determinism of the LTS, and
tests), which the EOS part builds on.

## Building

Requires [elan](https://github.com/leanprover/elan). The Lean toolchain and all
dependency versions are pinned in `lean-toolchain` and `lake-manifest.json`.

```
lake exe cache get
lake build
```
